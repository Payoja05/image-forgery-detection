# Assets

* `design_reference.webp` – the hand-drawn UI design reference the interface follows.
* `samples/` – four labelled images copied from the **held-out test split** of the synthetic
  dataset by `python -m training.make_samples` (first image of each type, not hand-picked),
  with their ground-truth masks and `samples.json`. They are derived from the Oxford-IIIT Pet
  Dataset (CC BY-SA 4.0). Labels and masks are ground truth, not model predictions.
