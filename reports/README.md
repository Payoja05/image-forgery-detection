# Reports

Files in this folder are **generated by code** — never edited by hand. The Model
Performance page of the app reads them.

| file | written by | content |
|---|---|---|
| `training_history.json` | `python -m training.train` | per-epoch training loss, validation loss, validation pixel IoU/F1, validation image ROC-AUC, best epoch, config |
| `test_metrics.json` | `python -m evaluation.evaluate_model` | test-split image-level metrics, confusion matrix, ROC curve, pixel-level metrics, per-type results, ELA / noise baselines, timing |
| `examples/` | `python -m evaluation.evaluate_model` | image / ground truth / predicted mask / probability for the first two test images of each type |
| `build_dataset.log`, `train.log`, `evaluate.log` | console logs of the runs above | |
